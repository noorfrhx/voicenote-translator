Fixes for the translation popup in WhatsApp Desktop.

## Changes

- **Popup stays on screen.** Long translations (or long originals) no longer run off the bottom of the screen; the popup is capped at the screen height and scrolls, and Copy, Original and Close stay visible.
- **Smooth scrolling.** Translate buttons and the popup now follow voice messages at 60 fps while you scroll, then drop back to a light check when nothing moves.
- **Keyboard shortcuts in the popup.** Esc or ⌘W closes it, ⌘C copies the translation (or your selection), Tab switches between translation and original.
- The popup hides when you switch to another app, and gives the keyboard back to WhatsApp when it closes.
- The popup shows "Original · German" (the detected language) while showing the original.

## Download

**`VoiceNote-Translator-1.0.1.dmg`**: open it and drag the app into Applications, replacing the old version. The browser extension is included in the app.

Signed with a Developer ID and notarized by Apple, so it opens without warnings.

If you loaded the browser extension from the app before, reload it in `chrome://extensions` after updating.
