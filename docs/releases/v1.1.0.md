VoiceNote Translator now updates itself.

## New

- **Automatic updates.** The app checks for new versions once a day. When one is out, the menu bar icon changes and the menu shows **Update to … Available**; click it to see what's new and install in one click. You can also choose **Check for Updates…** any time, or let updates download and install on their own (Settings → General → Updates).
- **The browser extension updates with the app.** If you installed it from Settings → Connections → Install Extension…, it refreshes itself after each app update. Otherwise the extension's toolbar popup tells you when a newer version is available.
- Updates are verified with the project's own signing key before they're installed, and the app is signed with a Developer ID and notarized by Apple.

## Download

**`VoiceNote-Translator-1.1.0.dmg`**: open it and drag the app into Applications. From this version on, future updates install from inside the app.

Requires macOS 14 or later and an API key from [OpenRouter](https://openrouter.ai/keys) or any OpenAI-compatible provider.
