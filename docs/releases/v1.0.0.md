First release of VoiceNote Translator: transcribe and translate WhatsApp voice messages on your Mac with one click, in WhatsApp Web and WhatsApp Desktop.

## Download

- **`VoiceNote-Translator-1.0.0.dmg`**: open it and drag the app into Applications. Recommended.
- `VoiceNote-Translator-1.0.0-mac.zip`: the same app, zipped.
- `VoiceNote-Translator-Connector-1.0.0.zip`: the browser extension on its own. You don't need this; the app ships the extension and installs it from Settings → Connections.

Requires macOS 14 or later and an API key from [OpenRouter](https://openrouter.ai/keys) (or any OpenAI-compatible provider). Setup steps are in the [README](https://github.com/noorfrhx/voicenote-translator#install).

## What's in it

- **Translate** button next to every voice message in WhatsApp Web (Chrome, Brave, Edge, Arc, Vivaldi) and WhatsApp Desktop.
- Whisper Large V3 Turbo + Claude Haiku 5.5 on OpenRouter by default; any OpenAI-compatible API and models configurable.
- Translate into any language; switch from the menu bar.
- Menu bar status for the browser extension, WhatsApp Desktop and the API; Settings window with General, Translation, Connections, History and About.
- API key stored in the Keychain; the extension is a thin connector with no network access.
- Results cached so each note is only paid for once; searchable history.
- Opens at login; the browser connection survives app restarts.
- About 1–2% CPU for the WhatsApp Desktop buttons while WhatsApp is in front, nothing in the background.

## Good to know

- This build is signed with a development certificate but not notarized. On first launch macOS may say it can't verify the app: right-click it → **Open** → **Open**.
- WhatsApp Desktop asks for two permissions: Accessibility (to place the buttons) and access to WhatsApp's data (to read voice notes). Both are read-only.
- Not affiliated with WhatsApp or Meta.
